# 新手村通关路线

> 一条不贪多的四周路线。每个任务都对应网页里的一张任务卡，完成后勾选即可积累修为。
> 核对日期：2026-11-11。

## 第 0 周：选导师（30 分钟）

先读 [横向对比](comparison.md)，然后只选 **一个** 主修 Agent：

- 想立刻在终端里干活 → **Claude Code** 或 **Codex**
- 想要可视化、看 Agent 自己开浏览器验收 → **Antigravity**
- 想拆开 Agent 看内部、写扩展 → **Pi** 或 **DeepSeek Harness**

> 不要五个一起学。先在一个工具里形成肌肉记忆，再迁移。

## 第 1 周：把 Agent 跑起来

**目标**：完成一次"提需求 → 改代码 → 验证"的完整闭环。

1. 按对应道场的「入村仪式」安装，跑通 `--version`。
2. 在空项目里让它创建一个最小页面/脚本。
3. 学会中断、继续、查看 diff、拒绝修改。
4. 写第一份项目规则文件（CLAUDE.md / AGENTS.md / GEMINI.md）。
5. 完成任务卡：**基础交互**、**项目记忆**、**权限/审批**。

**验收**：不用查教程，能独立启动会话并安全地接受/拒绝一次修改。

## 第 2 周：让 Agent 按你的规矩工作

**目标**：从"聊天"升级到"工作流"。

1. 配置项目规则：构建命令、测试命令、代码规范、禁止事项。
2. 学会 Plan 模式或等价的只读规划流程。
3. 用 Hooks / Rules / Patch 固化一个自动动作（格式化、lint、危险命令拦截）。
4. 接入一个 MCP server（数据库、GitHub 或文件系统），完成一次跨系统查询。
5. 完成任务卡：**规划模式**、**Hooks/规则**、**MCP**、**检查点/回滚**。

**验收**：新会话启动后，Agent 能自动遵守你的项目规范，且危险操作会被拦截。

## 第 3 周：并行与自动化

**目标**：让 Agent 脱离聊天窗口，进入脚本和 CI。

1. 用无头模式跑一次代码审查：`claude -p` / `pi --print` / `codex exec` / `agy -p` / `dsh --profile headless`。
2. 把结果输出成 JSON，接入一个脚本或 CI 步骤。
3. 学子代理/并行任务：把"调研 + 实现 + 测试"拆给不同 Agent。
4. 完成任务卡：**Headless**、**JSON 输出**、**Subagents/子代理**、**CI 集成**。

**验收**：一条命令能在无人值守的情况下完成一次可复现的检查，并给出非零退出码。

## 第 4 周：定制与平台化（选修）

按兴趣选一条支线：

- **Claude Code**：Hooks + Skills + Agent SDK，做团队专属工作流。
- **Pi**：写一个 TypeScript Extension 或 SDK 小工具。
- **Codex**：把云端任务与 GitHub 协作接进团队流程。
- **Antigravity**：Rules + MCP + Swarm（预览），做多 Agent 验收流水线。
- **DeepSeek Harness**：Profile + Patch + 自定义插件，搭一个隔离的运行环境。

**验收**：产出一个可复用的扩展/规则/脚本，并写一页说明文档。

## 每日固定动作

- 每天：跑一次 `npm run update`，看 `docs/UPDATE_LOG.md` 是否有官方变更。
- 学完一个功能：在网页里点亮，并在 `agents/<slug>/sources.md` 补一条来源。
- 遇到版本差异：先看官方文档，再改笔记，不要凭记忆改命令。
